NEXUS for Workflowy

Settings for the extension: hotkeys, the broker pairing, the deck's appearance and the tag vocabularies. Changes save as you make them. Hotkeys and settings sync across every Chrome browser signed in to this Google account; the broker token stays on this machine.

Hotkeys

Click a binding's Rebind button, then press the key combination you want to use. Every gesture acts on the Workflowy node under the mouse; the deck's own keys (the command palette, toggling the deck) are listed here too.

Action Binding
Tips
  • Chrome reserves bare F1, F5, F6, F11, and F12 for browser shortcuts — those will not reach this extension. Use a modifier (e.g. Ctrl+F12) if you want to use one of those keys.
  • Use modifier prefixes: Ctrl, Alt, Shift, Meta (Cmd on Mac, Win on Windows).
  • To restore the original default for one action, click its Rebind button and then press Escape to cancel without changing.

Local broker connection

This extension talks to a small broker program that runs automatically on your computer. The first time the broker runs, it creates a private token and saves it to a file on this machine. Paste that token here once to pair this browser with your local broker. After that, GLIMPSE just works on this computer.
Where do I find the token? When the broker starts up, it prints a line beginning with 🔑 that shows the path to the token file. Open that file and copy its entire contents into the box above.

Advanced: if you set the WORKFLOWY_BROKER_TOKEN environment variable for the MCP server yourself, paste that exact value instead. The token is stored only on this computer (it is never synced to other machines), because each machine's broker has its own token.

Appearance (the deck)

The deck is the rail at the edge of the Workflowy page with its drawers and the Reader. Its width and height are set by dragging the deck's inner edge, the outline's share by dragging the splitter, and the dock side from the Reader's View popover; these two choices are also in the deck's Settings drawer.
Default: Follow Workflowy. The deck reads the page's background and switches between its light and dark surfaces; pick one to pin it.
Default: Auto. The Reader's outline (the table-of-contents rows) sits beside the document when the Reader is at least 720 px wide, above it otherwise.
Default: on. On a left or right dock the Reader and a pinned panel take real space: Workflowy narrows to the room beside them instead of being covered. If Workflowy’s header or outline would not fit, the deck falls back to covering the page and says so once in the Jobs drawer’s Activity log. Top and bottom docks always cover.
Default: off. A panel (Anchor Docks, Slice groups, Jobs …) opens on the Reader’s inner side, towards the page; on, it opens on the outer side, towards the screen edge.
Three short cards shown the first time the rail appears: the rail, Anchor Docks, slice groups.

Tab alias

Default: on. When enabled, committing an alias in the deck's Tabs drawer also renames this browser tab using the label and position below, so you can tell several open Workflowy tabs apart at a glance. Clearing the alias hands the tab title back to Workflowy. The rename re-asserts itself as you navigate (Workflowy rewrites its own title on every zoom), and works the same in Chrome and Firefox. Turn this off to keep Workflowy's native tab titles even when an alias is set.
Default label: Workflowy, positioned before the alias. The label is the fixed word combined with this tab's alias to form the tab title. With the current settings the tab will read:

Workflowy - spine

Choose Before alias for <label> - <alias> or After alias for <alias> - <label>. The label may be any word (e.g. WFY); surrounding spaces are trimmed, and an empty label falls back to Workflowy.

GLIMPSE limits and the Reader

KB
Default: 500 KB. If an expanded Workflowy view serializes above this limit, GLIMPSE returns a clear glimpse_payload_too_large error instead of timing out. Raise only if you know your browser and MCP host can comfortably handle larger payloads.
chars
Default: 2000000. Maximum number of characters rendered into the Reader's document before the view is truncated with a footer note. Raise this to read very large documents in full; there is no hard upper limit (a huge value just builds a larger DOM and may render a touch slower). Minimum 1000.
chars
Default: 100000 (~100 KB). For a live view, the Reader pre-renders EVERY visible row on the server (instant row clicks) when the total visible text size is at or below this threshold; above it, it renders only the selected row on demand (one quick server round trip per click) so very large pseudo-documents stay responsive without an O(N²) pre-render. Set to 0 to always render on demand; raise it to pre-render larger trees.
px
Default: 100 px. Pushes the deck's TOP edge down from the top of the screen (when it is docked left or right, or at the top) so it clears Workflowy's own search box — handy when you paste boolean tag queries into search and don't want the deck covering them. Set to 0 to dock flush with the top. Clamped to the visible window height so the deck never collapses to nothing.
px
Default: 720 px. The width of the retired floating note-preview popup. Nothing reads it any more (the deck's width is set by dragging its edge); the value is kept so older settings import unchanged.

Saved tabs import

s
Default: 5 s. When the Saved Tabs import opens several tabs (tick entries, then Go), it waits this long between one tab and the next — opening Workflowy tabs too quickly may trigger its desktop-style re-login. 0 = no delay; maximum 60. Also adjustable with the − / + stepper at the top of the import dialog (Tabs drawer → Import); a running import picks up a change at its next tab.

Tags and folders

Default: wfy-🏷️. Comma-separated list of temporary “marker” tags. The toggle hotkey (default Ctrl+F10) adds or removes a marker tag on whatever node the cursor is over — a fast way to mark a few subtree roots, then click that tag in Workflowy to isolate them and press F8 to expand only those. The default marker carries the wfy- expand prefix, so a marked node is also F8-expandable. If you configure more than one marker tag, the hotkey shows a small numbered picker. Same input rules as expand prefixes: leading # optional, surrounding spaces ignored, emojis allowed, empty / internal-space entries dropped.
Absolute directory where F12+4 ("materialize note as a Markdown file") writes a new .md when the node has no Cartographer Root:/folder ancestor to anchor to. When such an ancestor does exist, F12+4 writes the file next to it and ignores this setting. Leave blank to require an ancestor folder; with no ancestor and no default set, F12+4 reports an actionable error instead of guessing. The folder must already exist on disk (the server verifies this before writing).
Export archives the daemon reads when a handle is not in Workflowy (node.export output_file writes them). One absolute folder; leave empty to turn archive reads off.

F8 slice postfixes

A slice tag can carry a hyphen-postfix that changes what F8 does with that node, WITHOUT removing it from the slice. For a base slice tag tag--a, the postfixed variant is tag--a--<word> (it still matches a #tag--a click by prefix, so it stays in the slice). These words are read by the server, which compiles the search string and the F8 expand/collapse plan — one place owns the meaning.
Default: expand. A node tagged tag--a--expand is the one F8 actually EXPANDS (a bare tag--a is membership/marker only). One word; leading # optional; empty falls back to the default.
Default: suppress. A node tagged tag--a--suppress is COLLAPSED by F8 (its subtree is hidden for this slice). Suppressing an ancestor that sits ABOVE the slice group's root is inert — zoom inside it and it's no longer suppressed.
Default: deprecated. A node tagged tag--a--deprecated STAYS in the slice (still matches a #tag--a click) but is dropped from the default membership view via the compiled search's negation (#tag--a -#tag--a--deprecated) and is collapsed by F8 (unless collapsing it would hide a live, non-deprecated descendant). Per-prefix: deprecating one tag does NOT evict a node still live via another of the group's tags.
A blanket suppressor list, INDEPENDENT of any slice. F8 never auto-expands a subtree rooted at a node carrying any of these tags, for ANY active slice group. Comma-separated; leading # optional; emojis allowed; may be left empty (no global suppressors).

Note sessions and Anchor Docks

A note session is a durable, discoverable topic container (one Workflowy node plus its subtree). It is marked ONLY by carrying a note-session tag in its name's trailing tag region — the words “note session” never appear in the node name; the tag alone defines it, and the node name is the topic. Storage is chronology; meaning is tags. Anchor Docks are the same vocabulary: the deck's Anchors drawer lists them.
Default: wfy-ns. Comma-separated list. A node is treated as a note session when its trailing tag region contains any of these tags. The first tag is the default applied when creating a new session. Same input rules as the other tag fields: leading # optional, surrounding spaces ignored, emojis allowed, empty / internal-space entries dropped.
Default: local. Comma-separated list of postfix words (bare words — no #, no --). A postfix appended to an anchor tag as <anchor-tag>--<word> (e.g. wfy-ns--local) marks a local anchor: it is still a real anchor (it nests, and still stops a descendants GLIMPSE at its boundary) but is hidden from the top-level anchor list. Use it for sub-anchors that only matter inside their parent. The first word is applied by create_anchor(local=true); all words are recognized when reading. Same input rules as the postfix fields (leading # optional, spaces ignored, empty / internal-space entries dropped).
Default: fav. Comma-separated list of postfix words (bare words — no #, no --). A postfix appended to an anchor tag as <anchor-tag>--<word> (e.g. wfy-ns--fav) marks a favorite anchor (starred, ⭐): it stays in every listing and anchors the favorites shortlist that dock.list and the deck's Anchors drawer show by default (falling back to the full inventory, with a notice naming the tag to use, when nothing is starred). The first word is applied by dock.create/dock.promote favorite=true; all words are recognized when reading. A favorite anchor that is also local carries both postfix tags (one per attribute). Same input rules as the postfix fields (leading # optional, spaces ignored, empty / internal-space entries dropped).
The tags the note-session system knows about. When capturing into a session, the agent chooses from these (merged with any tags already present in that session). Tags scattered elsewhere in Workflowy that are not listed here are invisible to this system. Comma-separated; may be left empty. The deck's Settings drawer shows this list read-only.
New note sessions are created under this node when no explicit parent is given. Paste a UUID and click Activate to confirm and save it. Leave blank to require an explicit parent at creation time — with no default and no explicit parent, session creation reports an actionable error rather than guessing a location.
Where you keep your Project Maps: a Workflowy node (its UUID, the 8-hex start of it, or an [ap:…] AP-ID). It is a pointer and nothing more. Agents read it through system.config.get (project_maps_location), and you can tell an agent to look there; scripts may use it to find a project's map. What goes into a Project Map, and how many you keep there, is entirely up to you: NEXUS never interprets, validates or requires anything inside it. Leave blank for none.
