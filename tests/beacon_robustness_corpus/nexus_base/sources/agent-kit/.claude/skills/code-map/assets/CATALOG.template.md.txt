# Code map: slice label catalog

**Read this first.** Important functions, classes and regions in this repository carry `@beacon[...]` comment blocks that give them labels. This catalog lists every label in use: what it covers, and how many symbols carry it. Each label's slice (every symbol carrying it, with its signature and documentation, gathered from all files) is in `slices/<label>.md`, generated from the source.

How this file is kept: agents write and update the descriptions; the code-map skill's script (`labels --write`) maintains the **Symbols** counts and adds a row for any new label under *New labels*, to be described and moved into the right section. Keep each description to one or two sentences: what the label covers, where to start, and anything a newcomer should know.
